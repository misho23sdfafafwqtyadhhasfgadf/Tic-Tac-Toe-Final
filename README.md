📝 Descripción y Cómo Jugar
Este es el clásico juego de Tic-Tac-Toe (Gato o Tres en Raya) desarrollado en Python utilizando la librería Tkinter para la interfaz gráfica. El proyecto fue desarrollado siguiendo un flujo de trabajo profesional con Git y GitHub (Feature Branching).
Cómo jugar:
1.	El juego es para dos jugadores (X y O).
2.	El jugador 1 usa la "X" (Rojo) y el jugador 2 usa la "O" (Azul).
3.	Gana el primero en alinear 3 marcas iguales.
4.	El botón "Reiniciar Juego" permite limpiar el tablero sin cerrar la ventana.
